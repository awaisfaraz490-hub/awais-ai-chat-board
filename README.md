🤖 Awais AI Chat Board

An AI-powered chat board that allows users to upload PDF, TXT, Markdown, and image files and ask questions about their uploaded documents. It also supports General AI chat when no file is selected.

✨ Features
🔐 User Login & Authentication
📄 PDF document upload
📝 TXT and Markdown file support
🖼️ Image file support
🤖 AI-powered question answering
💬 General AI chat without a selected file
🎙️ Voice input
📚 Multiple document selection
🗑️ Delete uploaded documents
🧹 Clear chat history
📱 Responsive mobile-friendly interface
🌐 Deployed on Vercel
🗄️ Supabase database integration

    🚀 How It Works
Create an account / login.
Upload a PDF, TXT, Markdown, or image file.
Select the document you want to use.
Ask your question.
The AI analyzes the selected document and provides an answer.
If no document is selected, the question is automatically handled by General AI.
